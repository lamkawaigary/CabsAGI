# 行程管理頁面重建規格書

## 核心理念
行程狀態機控制完整流程，乘客和司機各自看到該看的狀態和動作。

---

## 行程狀態機 (Trip Status Machine)

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   ┌──────────┐    司機批准     ┌───────────┐   司機開始  ┌─────┐ │
│   │  OPEN    │ ────────────→  │ CONFIRMED │ ─────────→ │INPRO│ │
│   │ (開放中) │                │ (已確認)   │            │GRESS│ │
│   └──────────┘                └───────────┘            └──┬──┘ │
│        │                           │                         │    │
│        │ 取消                      │ 取消                    │ 完成│
│        ↓                           ↓                         ↓    ↓
│   ┌──────────┐                ┌──────────┐            ┌──────────┐
│   │CANCELLED │                │CANCELLED │            │COMPLETED │
│   └──────────┘                └──────────┘            └──────────┘
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

---

## 狀態定義

| 狀態 | 名稱 | 意義 | 可用動作 |
|------|------|------|----------|
| `OPEN` | 開放中 | 司機發布行程，等待乘客申請/批准 | 司機：批准/拒絕乘客、取消行程 |
| `CONFIRMED` | 已確認 | 乘客已湊齊，準備出發 | 司機：開始行程、取消行程 |
| `IN_PROGRESS` | 行程中 | 正在進行中 | 司機：掃描上車、完成行程 |
| `COMPLETED` | 已完成 | 行程結束 | 無 |
| `CANCELLED` | 已取消 | 行程取消 | 無 |
| `EXPIRED` | 已過期 | 時間到期自動作廢 | 無 |

## 乘客視角 - 我的行程 (MyTripsPage)

### 顯示邏輯
根據用戶在行程中的狀態顯示不同的卡片和動作按鈕。

### 狀態標籤 (Passenger Status)
| 顯示狀態 | 條件 |
|----------|------|
| 🟢 待批准 | 在 `pendingPassengers` 中 |
| 🟡 已批准 | 在 `passengers` 中，status = OPEN |
| 🔵 已確認 | status = CONFIRMED |
| 🔵 行程中 | status = IN_PROGRESS |
| ✅ 已完成 | status = COMPLETED |
| ❌ 已取消 | status = CANCELLED |
| ❌ 已拒絕 | 在 `rejectedPassengers` 中 |

### 卡片顯示內容
```
┌────────────────────────────────────┐
│ [狀態標籤]              [時間]     │
│                                    │
│ 📍 [上車點] → [下車點]             │
│                                    │
│ 司機：XXX  │ 座位：X/X             │
│                                    │
│ [動作按鈕區]                      │
│                                    │
│ ┌─ Progress Bar ────────────────┐  │
│ │ ●──────●──────●──────●        │  │
│ └───────────────────────────────┘  │
└────────────────────────────────────┘
```

### 動作按鈕
| 行程狀態 | 乘客動作 |
|----------|----------|
| OPEN (待批准) | 顯示「等待司機批准」，不可點擊 |
| OPEN (已批准) | 「離開行程」(leave) |
| CONFIRMED | 「確認乘車」(confirm) + 「離開行程」 |
| IN_PROGRESS | 「已上車」(被動) |
| COMPLETED | 「評價司機」(待開發) |
| CANCELLED | 無動作 |

### QR Code 功能
- 在 `CONFIRMED` 和 `IN_PROGRESS` 狀態顯示「🎫 查看上車令牌」按鈕
- 彈窗顯示 QR Code 和 4 位驗證碼
- 司機掃描後，乘客狀態更新為「已上車」

## 司機視角 - 我的行程 (DriverTripsPage)

### 顯示邏輯
司機只能看到自己創建的行程。

### 卡片顯示內容
```
┌────────────────────────────────────┐
│ [狀態標籤]              [時間]     │
│                                    │
│ 📍 [上車點] → [下車點]             │
│                                    │
│ 已加入：X  │ 剩餘：X/X             │
│                                    │
│ ┌─ 待批准乘客 ─────────────────┐  │
│ │ 👤 乘客1  [批准] [拒絕]       │  │
│ │ 👤 乘客2  [批准] [拒絕]       │  │
│ └───────────────────────────────┘  │
│                                    │
│ [動作按鈕區]                        │
└────────────────────────────────────┘
```

### 動作按鈕
| 行程狀態 | 司機動作 |
|----------|----------|
| OPEN | 「✅ 確認出發」(→ CONFIRMED) |
| CONFIRMED | 「🚗 開始行程」(→ IN_PROGRESS) |
| IN_PROGRESS | 「📷 掃描上車」+ 「✅ 完成行程」(→ COMPLETED) |
| 任何非結束狀態 | 「❌ 取消行程」(→ CANCELLED) |

### 待批准乘客管理
- 列表顯示 `pendingPassengers`
- 每個乘客有 [批准] 和 [拒絕] 按鈕
- 批准後移到 `passengers`，`availableSeats - 1`
- 拒絕後移到 `rejectedPassengers`

## 數據操作 (TripService)

### 乘客操作
| 操作 | 方法 | 說明 |
|------|------|------|
| 申請加入 | `requestJoin(tripId, passenger)` | 加入 `pendingPassengers` |
| 離開行程 | `passengerLeave(tripId, oderId)` | 從 `passengers` 或 `pendingPassengers` 移除 |
| 確認乘車 | `confirm(tripId, oderId)` | 加入 `confirmedByPassengers` |

### 司機操作
| 操作 | 方法 | 說明 |
|------|------|------|
| 批准乘客 | `approvePassenger(tripId, oderId)` | 從 pending → passengers |
| 拒絕乘客 | `rejectPassenger(tripId, oderId)` | 從 pending → rejected |
| 標記上車 | `markPassengerOnboarded(tripId, oderId)` | `passengers[].onboarded = true` |
| 開始行程 | `updateStatus(tripId, 'IN_PROGRESS')` | status 改變 |
| 完成行程 | `updateStatus(tripId, 'COMPLETED')` | status 改變 |
| 取消行程 | `updateStatus(tripId, 'CANCELLED')` | status 改變 |

### 查詢方法
| 操作 | 方法 | 說明 |
|------|------|------|
| 司機行程 | `getByDriver(driverId)` | 查詢 `driverId == currentUser.id` |
| 乘客行程 | `getByPassenger(passengerId)` | 查詢 `passengers[].oderId == oderId` 或 `pendingPassengers[].oderId == oderId` |
